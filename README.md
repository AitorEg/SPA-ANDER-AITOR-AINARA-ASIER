Descripción del proyecto

Aplicación web desarrollada para el Instituto Cuatrovientos con el fin de dar a conocer los libros de la antigua biblioteca, organizar actividades de intercambio y fomentar la participación del alumnado en el nuevo espacio de descanso.

Estructura del Repositorio y Ramas

Este proyecto implementa dos fases evolutivas dentro del mismo repositorio mediante una estrategia de ramas:

main: Versión 1 - Web estática multipágina desarrollada con Bootstrap 5.3 (incluye páginas independientes para inicio, actividades, contacto y registro).

SPA: Versión 2 - Single Page Application (SPA) con un único documento index.html y navegación dinámica mediante JavaScript nativo, gestión de eventos, filtros y formularios interactivos.
